# Déploiement statique

Le prototype ne nécessite aucune commande de build.

## GitHub Pages

Le dossier peut être publié tel quel avec GitHub Pages. Une fois le site configuré, les mises à jour futures consisteront uniquement à remplacer les fichiers du prototype dans le dépôt : l'URL restera la même.

## Cloudflare Pages

Même principe :
- framework preset : None
- build command : vide
- output directory : le dossier contenant `index.html`

Dans Réglages, la page doit afficher :
