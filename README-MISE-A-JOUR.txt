COUPLE — MISE À JOUR v0.8.1
Navigation basse native + parcours et textes épurés

INSTALLATION MANUELLE SUR GITHUB

1. Décompressez ce ZIP.
2. Dans le dépôt 6p8gsf4ctt-prog/couple, remplacez le fichier index.html situé à la racine par celui contenu dans ce ZIP.
3. Validez le commit sur la branche main.
   Message conseillé : V0.8.1 - navigation basse et parcours épuré
4. Attendez la publication GitHub Pages.
5. Sur l'iPhone, fermez complètement Couple puis rouvrez l'application depuis l'écran d'accueil.

IMPORTANT
- Le fichier index.html doit rester à la racine du dépôt.
- Les données locales existantes sont conservées.
- Il n'est pas nécessaire de remplacer app.js ou styles.css : la version publiée de Couple reste autonome dans index.html.
