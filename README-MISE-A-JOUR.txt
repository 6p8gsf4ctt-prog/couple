COUPLE — V2.2 « FLUIDITÉ & INTERACTIONS »

INSTALLATION
1. Décompressez Couple-V2-2-Fluidite-Interactions.zip.
2. Remplacez le fichier index.html à la racine du dépôt Couple.
3. Validez le changement puis attendez la mise à jour de GitHub Pages.
4. Sur iPhone, fermez complètement l’application ajoutée à l’écran d’accueil puis rouvrez-la.

DONNÉES
- La clé locale reste couple-v2-1-electric afin de conserver les données de la V2.1/V2.1.1.
- Le prototype reste local : il ne synchronise pas encore réellement deux téléphones.
- Le changement de perspective dans Réglages permet de tester les réactions de l’autre partenaire.

NAVIGATION
- Le bouton retour utilise maintenant une vraie pile de navigation.
- Un retour revient à l’écran réellement consulté juste avant.
- La position de défilement de la liste précédente est restaurée.
- Un swipe depuis le bord gauche vers la droite reproduit le retour, dans l’esprit d’iOS.
- La navigation inférieure reste une navigation racine et repart volontairement au niveau principal de l’espace choisi.

SECRET
- Un bon reçu non découvert n’apparaît plus dans le Carnet.
- Son titre et son message ne sont pas montrés sur l’accueil.
- Le contenu n’est révélé qu’au grattage.
