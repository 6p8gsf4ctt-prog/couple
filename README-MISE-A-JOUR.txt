COUPLE — MISE À JOUR v0.7.2
Stabilité mobile + Carnet uniformisé

INSTALLATION MANUELLE SUR GITHUB

1. Décompressez ce fichier ZIP sur votre appareil ou ordinateur.
2. Ouvrez le dépôt GitHub : 6p8gsf4ctt-prog/couple
3. À la RACINE du dépôt, remplacez le fichier index.html actuel par le
   fichier index.html présent dans ce ZIP.
4. Validez le commit sur la branche main.
   Message conseillé :
   V0.7.2 - stabilité mobile et carnet uniformisé
5. Attendez la mise à jour de GitHub Pages, puis fermez complètement
   l'application Couple sur le smartphone et rouvrez-la.

IMPORTANT
- Ne placez pas index.html dans un sous-dossier : il doit remplacer celui
  qui se trouve déjà à la racine.
- Le stockage local existant est conservé : la clé localStorage de la
  version 0.7 n'est pas modifiée par cette mise à jour.
- Évitez d'effacer les données du site Safari si vous souhaitez conserver
  les bons de test déjà enregistrés.
- Les anciens fichiers app.js et styles.css du dépôt ne sont pas utilisés
  par la version publiée actuelle ; cette mise à jour ne nécessite pas
  de les remplacer.
