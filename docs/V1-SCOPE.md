# Couple — Périmètre V1

## Inclus dans la V1

### Comptes
- exactement deux utilisateurs
- authentification obligatoire
- inscription publique désactivée
- association des deux comptes au même couple

### Chèques
- créer un chèque
- enregistrer en brouillon
- passer en état prêt
- offrir
- découvrir
- marquer comme utilisé
- conserver l'historique

### Secret
- le destinataire ne voit rien avant l'offre
- après l'offre, il sait qu'un bon l'attend
- le contenu reste inaccessible jusqu'à la révélation
- notification générique uniquement

### Création
- bibliothèque
- « Me surprendre »
- création personnalisée

### Bibliothèque
- 100+ idées
- catégories :
  - Romantique
  - Sorties
  - Aventure
  - Maison
  - Petites attentions
  - Intime / Couple

### Carnet
- reçus
- offerts
- disponibles
- utilisés
- affichage type album / collection

### Design
- 3 familles de chèques
- direction Carnet Ivoire + discipline Lumière
- une interaction principale de révélation très soignée

### Sécurité
- Supabase Auth
- RLS
- aucun secret dans GitHub
- notifications non sensibles
- verrouillage local / Face ID
