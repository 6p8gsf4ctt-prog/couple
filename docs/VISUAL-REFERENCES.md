# Références visuelles — règle d'interprétation

Les images du dossier `references/` ont été validées comme références d'univers, de hiérarchie, de composition et de parcours.

Elles ont été produites par génération visuelle et peuvent contenir de petits textes ou contrôles illustratifs qui ne constituent pas automatiquement une décision produit.

## Ordre d'autorité

En cas de contradiction :

1. `docs/DECISIONS.md`
2. `docs/V1-SCOPE.md`
3. `docs/PRODUCT.md`
4. `docs/DESIGN.md`
5. `docs/UX-FLOWS.md`
6. images de référence

## Exemples

La V1 conserve notamment ces règles même si une image illustre autre chose :
- pas de confettis
- pas de KPI ou gamification
- pas de partage public du contenu intime
- destinataire V1 = partenaire associé
- conservation automatique après découverte
- souvenirs hors navigation principale V1
- aucune inscription publique
- données et application privées même si le dépôt GitHub est public
