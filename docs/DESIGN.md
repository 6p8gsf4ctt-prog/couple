# Couple — Direction design

## Direction officielle

**Carnet Ivoire + discipline Lumière + douceur organique**

La chaleur d'un bel objet papier, la sobriété d'une interface mobile haut de gamme et une douceur suffisamment organique pour éviter toute sensation institutionnelle.

---

## Principes fixes

### 1. Le chèque est l'objet principal
L'interface doit disparaître autour de lui.

### 2. L'espace est un matériau
Pas de densité excessive.

### 3. La douceur ne signifie pas « tout arrondir »
Les formes sont assouplies, pas enfantines.

### 4. Le papier reste contemporain
Texture très légère, lumière diffuse, bords nets mais tactiles.

### 5. Le romantisme vient du contenu
Pas de cœur décoratif omniprésent, fleurs systématiques ou codes Saint-Valentin.

### 6. L'animation doit sembler physique
Masse, friction, profondeur et résistance légère.

---

## Palette

Base :
- ivoire chaud
- blanc cassé
- graphite
- sable

Accents :
- rose poudré
- bordeaux doux
- champagne très discret

Le bordeaux sert à créer un point d'attention, pas à colorer toute l'interface.

---

## Typographie

### Interface
Sans-serif claire, chaleureuse et lisible.

### Chèque
Serif éditoriale élégante.

### Éléments personnels
Une écriture manuscrite discrète peut être utilisée avec parcimonie pour donner une présence humaine.

---

# Chèque Signature

## Statut
**Structure V1 officielle**

## Construction
- format horizontal
- coins doux
- talon latéral
- perforation verticale
- titre « BON POUR »
- titre du bon
- message court
- destinataire / expéditeur
- validité uniquement si renseignée
- marque d'identité discrète

## Règles de contenu
La structure doit absorber :
- titre court
- titre long
- message absent
- message court
- message long raisonnable
- validité présente ou absente

Le texte ne doit jamais casser l'objet.

## État utilisé
- le chèque reste dans le Carnet
- marque/tampon « UTILISÉ » discret
- date d'utilisation
- aucune disparition
- aucune notion de retard ou performance

---

# Révélation

## Interaction officielle

1. enveloppe fermée
2. prise du bord du chèque
3. tirage suivant le doigt
4. légère résistance
5. ouverture progressive de l'enveloppe
6. point de bascule
7. haptique subtile
8. sortie complète
9. enveloppe qui s'efface/recul doucement
10. chèque recentré
11. retour discret des contrôles

## Geste interrompu
Avant le point de bascule :
- le chèque revient doucement dans l'enveloppe
- aucune pénalité
- l'utilisateur peut recommencer

Après le point de bascule :
- la révélation est considérée comme effectuée

## Interdits
- confettis
- rebonds décoratifs
- gamification
- effets sonores agressifs
- animation automatique qui retire le contrôle à l'utilisateur

# Accueil

Éléments centraux :

Navigation V1 de référence :
- Carnet
- Idées

# Bibliothèque

Point d'entrée éditorial :

**Qu'est-ce qui ferait plaisir aujourd'hui ?**

Catégories :
- Romantique
- Sorties
- Aventure
- Maison
- Petites attentions
- Intime / Couple

Afficher une sélection limitée par catégorie plutôt qu'une grille de 100 éléments.

---

# Carnet

Le Carnet est un album.

À évoquer :
- pile
- pages
- chevauchements
- talons
- traces d'utilisation
- continuité dans le temps

À éviter :
- liste de tâches
- tableaux de statistiques
- compteurs de performance
- KPI
